# MARVEL — MULTIVERSE ROSTER

Landing page fan-made untuk Special Task Web Development Bayucaraka ITS 2027. Delapan karakter Marvel tampil di arena seleksi dengan profil, ilustrasi, dan tema warna masing-masing.

## Menjalankan lokal

Ekstrak folder proyek lalu buka `index.html` di Chrome, Edge, Firefox, atau Safari versi terbaru. Tidak perlu instalasi, build, atau koneksi internet.

## Teknologi dan interaksi

- HTML5 semantik dan CSS3 murni. Tidak ada JavaScript, framework, atau dependensi runtime.
- Delapan radio input native dengan label kartu. `:checked` dan `:has()` menyinkronkan profil, tema arena, dan kartu aktif.
- Pilih karakter lewat klik atau sentuhan. Untuk keyboard, tekan Tab sampai masuk ke roster, lalu gunakan tombol panah untuk memilih.
- Roster dapat digeser secara horizontal di layar sempit. CSS juga menyediakan fokus visual serta dukungan `prefers-reduced-motion`.
- Aset visual disimpan di `assets/`. Ilustrasi fan art dibuat khusus untuk proyek ini. Nama dan desain karakter mengacu pada Marvel. Proyek ini bersifat edukatif dan tidak terafiliasi dengan Marvel atau Disney.

## Struktur

- `index.html` — navigasi, arena, roster, fitur, dan footer.
- `style.css` — layout, tema karakter, animasi, dan breakpoint.
- `assets/` — delapan ilustrasi lokal.
- `AI-LOG.md` — catatan bantuan AI.
